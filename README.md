# Shantir_Shodai
Modern responsive e-commerce website with glassmorphism UI, shopping cart functionality, responsive layouts, animations, and clean frontend design using HTML, CSS, and JavaScript.<br>
<b>Overview<br>

Shantir Shodai is a modern responsive e-commerce website built using HTML, CSS, and JavaScript. The project focuses on clean UI/UX design, smooth animations, <br>glassmorphism effects, responsive layouts, and interactive shopping cart functionality.<br>

The website is designed to provide a premium online shopping experience with modern frontend development practices.<br>

<b>Features<br>
Modern responsive design<br>
Glassmorphism UI elements<br>
Sticky navigation header<br>
Product cards with hover animations<br>
Shopping cart sidebar<br>
Wishlist functionality<br>
Search bar UI<br>
Category navigation<br>
Promotional banner with countdown timer<br>
Toast notifications<br>
Fully responsive for mobile, tablet, and desktop<br>
Smooth transitions and animations<br>
Modern color palette and typography<br>
